# طاولة الاجتماعات — من يفعل ماذا

كل شخصية لها **اسم ولقب ومهمة محددة وبنود تقييم مسندة إليها حصرًا**.
التعريف الكامل (نص البرومبت لكل شخصية) داخل `src/profiles/rabeh_article_ar.mjs` تحت `roster`.

---

## مجلس التحرير

| الشخصية | متى تتكلم | مسؤوليتها |
|---|---|---|
| 🪑 **مروان الحكم** — رئيس المجلس | مرتان في كل دورة | يثبّت المخطط قبل الكتابة، ثم يحسم تعارض النقاد ويرفض الملاحظات الضعيفة ويُخرج موجز تعديل واحد ≤ ١٢ بندًا. **لا يكتب ولا يعدّل بنفسه.** |
| 🧭 **سلمى القاسم** — مديرة الاستراتيجية | قبل الكتابة | نية الباحث الحقيقية، مطابقة النوع المعلن، الزاوية التنافسية، الأسئلة الإلزامية، رحلة القارئ. ترفض أي بنية تبدأ بالبيع. |

## ورشة الكتابة

| الشخصية | مسؤوليتها |
|---|---|
| 🏗️ **ياسر البنّاء** — مهندس الإحاطة | الهيكل + ميزانية كلمات لكل قسم + خريطة الكلمات المفتاحية + خريطة الربط الداخلي + مواضع الجداول والصور + قائمة الادعاءات التي تحتاج مصدرًا |
| ✍️ **ريم الكاتبة** — الكاتبة الأولى | المسودة الكاملة من المخطط وحزمة الأدلة المعتمدة **فقط** |
| 🎬 **طارق الراوي** — محرر السرد | يعيد هندسة التدفق والانتقالات، يحذف القفزات المنطقية والتكرار، يضمن وجود سيناريو ملموس. **لا يضيف معلومة ولا يحذف رابطًا.** |
| 🖋️ **هدى الصياغة** — محررة اللغة | النحو والترقيم وأدوات الربط وتنويع بدايات الجمل وإزالة نبرة الذكاء الاصطناعي. **لا تغيّر المعنى.** |
| 🛠️ **وضع التعديل** | ينفّذ موجز المجلس بندًا بندًا، ولا ينفّذ ما رفضه المجلس |

## فريق البحث والاستشهادات

| الشخصية | مسؤوليتها |
|---|---|
| 🔎 **نورة السند** | تبحث فعليًا على الإنترنت. ترتّب المصادر: رسمي ← حكومي ← جامعي ← تقارير عالمية ← مدونات متخصصة. تسجّل الرقم كما ورد والرابط المباشر والتاريخ. |
| 🌐 **فحص الروابط** *(كود)* | طلب HTTP فعلي لكل رابط قبل الاستشهاد به |
| 🧪 **د. عمر التدقيق** | يرفض: الرابط الميت، رابط الصفحة الرئيسية، الناقل عن ناقل، الرقم المحرَّف، الدليل القديم، والمكرر |

## لجنة النقد — ٩ أعضاء على الطاولة

| الشخصية | بنودها |
|---|---|
| 📈 **خالد المُدقّق** — SEO | `seo` · `semantic_seo` · `competitiveness` |
| 🤖 **ليان الإجابة** — AEO/GEO | `aeo_geo` · `readability` |
| 🎯 **فهد المُقنع** — الإقناع | `copywriting` · `conversion_potential` |
| 🛡️ **أ. منال الثقة** — E-E-A-T | `eeat` · `sourcing` |
| 📍 **بدر السوق** — السوق المحلي | `local_seo` |
| 🔥 **زياد الناقد** — الفريق الأحمر | `content_quality` · `search_intent` |
| 🕸️ **دانة الروابط** — Topic Cluster | `internal_linking` |
| 📖 **سارة السرد** — تسلسل الأحداث | `narrative` |
| 📝 **أ. جواهر اللغة** — الصياغة | `language` |

**قاعدة صارمة:** لا يقيّم أي ناقد بنود زملائه. عند التجميع تُؤخذ **أدنى** درجة لكل بند.

## الرقابة الآلية

| الجهة | الدور |
|---|---|
| 🔍 **المفتش الآلي** *(كود)* | ٢٣ فحصًا رقميًا. مخرجاته حقائق تدخل موجز التعديل إجباريًا |
| 🚪 **البوابة** *(كود)* | تعيد حساب الشروط بنفسها ولا تكتفي بقرار رئيس المجلس |
| ⚖️ **هيئة التدقيق النهائي** | تقرير التحقق بمراحله السبع: النوع، Scorecard، مراجعة تفصيلية بـ١١ محورًا، Opportunities، Critical Issues، القرار، التقييم النهائي |
