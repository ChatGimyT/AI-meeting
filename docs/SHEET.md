# لوحة التحكم في شيت جوجل

تملأ صفًا، تعلّم ✅ في عمود **تشغيل**، فيلتقطه المحرك خلال دقيقة ويكتب لك المقال والتقارير
والمقارنة بالمقال المرجعي في الصف نفسه.

**الشيت:** [1_LWkR3yYKsKQP9jcjPdi96D8lzTCWYmz5TF3FOsZZGw](https://docs.google.com/spreadsheets/d/1_LWkR3yYKsKQP9jcjPdi96D8lzTCWYmz5TF3FOsZZGw/edit) — الورقة: `الورقة1`

---

## ١. تجهيز الشيت (مرة واحدة)

الشيت فارغ الآن. جهّزه هكذا:

1. افتح الشيت ← **File → Import → Upload** وارفع [`benchmark/sheet-template.csv`](../benchmark/sheet-template.csv).
2. اختر **Replace current sheet** ثم **Import data**.
3. حدّد العمود **A (تشغيل)** كاملًا ← **Insert → Checkbox** ليصير مربع اختيار حقيقي.
4. (اختياري) جمّد الصف الأول: **View → Freeze → 1 row**.

> **لا تلصق ملف الـ CSV بـ Ctrl+V.** بعض الخلايا متعددة الأسطر (العناوين، الروابط)،
> واللصق المباشر يكسرها. الاستيراد وحده يتعامل معها بشكل صحيح.
>
> بديل يدوي: الصف الأول موجود سطرًا واحدًا في [`benchmark/sheet-headers.txt`](../benchmark/sheet-headers.txt) — الصقه في `A1` ثم املأ الحقول بنفسك.

## ٢. أعمدة المدخلات

| العمود | إلزامي | الصيغة |
|---|---|---|
| **تشغيل** | ✅ | مربع اختيار — علّمه ليبدأ التنفيذ |
| **الحالة** | — | يكتبها المحرك؛ اتركها فارغة |
| **الملف التعريفي** | ✅ | `rabeh_article_ar_deepseek` · `rabeh_article_ar` · `rabeh_refresh_ar` · `social_posts_deepseek` |
| **عنوان المقال** | ✅ | نص |
| **الهدف** | — | ما الذي يحققه المقال |

| **السوق المستهدف** | — | مثال: `السعودية` |

| **تكرار الكلمة** | — | رقم؛ يُوزَّع آليًا على الأقسام |
| **الكلمات الثانوية** | — | **سطر لكل كلمة** |
| **الكلمات المرتبطة** | — | سطر لكل كلمة |
| **العناوين الداخلية** | — | سطر لكل عنوان. **فارغ = يبني المحرك الهيكل بنفسه** |
| **الروابط الداخلية** | — | سطر لكل رابط بالصيغة: `نص الأنكور \| https://...` |
| **استشهادات إلزامية** | — | سطر لكل استشهاد بالصيغة: `الجهة — «العنوان»: الرابط — المعلومة` |
| **دور المقالة** | — | `Pillar` أو `Cluster` |
| **المقالة الحالية** | لملف التحديث | النص الكامل للمقالة المنشورة |
| **ملاحظات** | — | أي توجيه إضافي |

> **مهم مع DeepSeek:** لا توجد أداة بحث على الإنترنت عبر الـ API، فأي رقم لا تضعه في
> **استشهادات إلزامية** سيُرفض ولن يدخل المقال. هذا سلوك مقصود — لا رقم بلا مصدر.
> اترك العمود فارغًا إن أردت مقالًا بلا إحصائيات.

لسطر جديد داخل خلية واحدة في Google Sheets: **Alt + Enter**.

## ٤. التشغيل

1. فعّل الـ workflow في n8n (مفتاح **Active**).
2. علّم ✅ في عمود **تشغيل** للصف الذي تريده.
3. خلال دقيقة تتحول **الحالة** إلى `⏳ قيد التنفيذ`.
4. بعد ٦–١٥ دقيقة تمتلئ أعمدة النتائج.

**صف واحد في كل دورة تشغيل.** إن علّمت عدة صفوف، تُنفَّذ بالترتيب دقيقة بعد دقيقة.

### إعادة تشغيل صف

امسح محتوى خلية **الحالة** واترك ✅ مُعلَّمًا — سيُلتقط الصف من جديد في الدورة التالية.

### إيقاف الاستطلاع

عطّل الـ workflow، أو عطّل عقدة `⏱️ Sheet Poll` وحدها إن أردت إبقاء المداخل الأخرى
(التشغيل اليدوي، النموذج، الـ Webhook) عاملة.

## ٥. تغيير الشيت أو أسماء الأعمدة

كل شيء في مكان واحد: عقدة **`📚 Profiles Registry`** ← كتلة `const SHEET`.

<div dir="ltr">

```js
const SHEET = {
  document_id: '1_LWkR3yYKsKQP9jcjPdi96D8lzTCWYmz5TF3FOsZZGw',
  sheet_name: 'الورقة1',
  in:  { run: 'تشغيل', title: 'عنوان المقال', /* … */ },
  out: { status: 'الحالة', article: 'المقال', /* … */ }
};
```

</div>

غيّرت اسم عمود؟ غيّره هنا أيضًا. ثم حدّث `documentId` و`sheetName` في عقدتَي
`📊 Read Sheet Rows` و`📝 Sheets: …`.

من المستودع، سطر واحد يعيد البناء بشيت مختلف:

<div dir="ltr">

```bash
npm run build -- --sheet-id=<ID> --sheet-tab='الورقة1' \
  --sheets-credential-id=<CRED_ID> --sheets-credential-type=googleSheetsOAuth2Api
npm run sheet:template        # يعيد توليد قالب الأعمدة من نفس التعريف
```

</div>

## ٦. حل المشكلات

| العَرَض | السبب | الحل |
|---|---|---|
| لا شيء يحدث بعد التعليم | الـ workflow غير مفعّل | فعّل **Active** |
| `The resource you are requesting could not be found` | اسم الورقة لا يطابق | تأكد أن اسمها `الورقة1` حرفيًا |
| الروابط الداخلية لم تُستخدم | صيغة الخلية | `نص الأنكور \| https://...` سطرًا لكل رابط (Alt+Enter) |
| العناوين اندمجت في عنوان واحد | لُصقت بفواصل | سطر لكل عنوان (Alt+Enter) |
| المقال بلا إحصائيات | لا استشهادات إلزامية مع DeepSeek | املأ عمود **استشهادات إلزامية** |
| خلية المقال مقصوصة | حد Google Sheets 50,000 حرف | المحرك يقصّ عند 45,000؛ النص الكامل في مخرجات `📦 Publish Pack` |
| `⛔ الطلب ناقص` | حقل إلزامي فارغ | السبب مكتوب في عمود **المخالفات الباقية** |
