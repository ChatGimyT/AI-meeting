# تقارير SEO — مركز العوجان

تقريران (أسبوعي وشهري) بيسحبوا مواضع الكلمات من Google Search Console،
بيكتبوا في شيت، بيبنوا عرض تقديمي، وبيبعتوا إيميل — **على محرك واحد**.

## اللي اتغيّر في v4

| المشكلة | الحل |
|---|---|
| المنثلي كان بياخد رقم أعلى صفحة ترتيبًا بدل الصفحة المستهدفة | كل كلمة ليها رابط، والرقم = الصفحة نفسها (`strict`) |
| التقريران بيحسبوا بطريقتين مختلفتين | حساب واحد في `src/lib/gsc.js` + ١٦ نود مشترك بالحرف |
| حارس اتقصاص رد جوجل عمره ما اشتغل | بيتقارن بالحد المطلوب فعلًا |
| فشل السحب كان بيتقال للعميل «اختفت» | تلات حالات منفصلة: فشل · مفيش ظهور · من الأرشيف |
| رابط غلط بيطلّع «مفيش ظهور» لصفحة شغالة | فحص كانوني لكل رابط + شهادة من جوجل نفسه |
| التنبيهات التقنية بتروح لدومين رابح بس | الفلتر اتشال — التنبيه لكل المستلمين |
| إعادة الإرسال على سيرفر رافض | تشخيص السبب + مسار Gmail API بديل |

الأرقام والتفاصيل: **[`docs/VERIFICATION.md`](docs/VERIFICATION.md)**

## التشغيل

<div dir="ltr">

```bash
node build.mjs                                  # يبني الملفين في dist/
node tools/test.mjs                             # ٧٥ تأكيد — بلا شبكة
node tools/simulate.mjs --cadence=monthly --scenario=threePages

node tools/extract-keywords.mjs --xlsx=<ملف>    # يحدّث قائمة الكلمات
node tools/verify-pages.mjs                     # يتأكد إن الروابط كانونية
```

</div>

## الاستيراد في n8n

استورد `dist/ALOJAN-Monthly-v4.json` و`dist/ALOJAN-Weekly-v4.json`.
الكريدنشيال المربوطة زي ما هي (`rabeh.seven.b` لجوجل و`Rabeh SMTP` للبريد).

**النودات الجديدة اللي محتاجة انتباه:**

| النود | ملاحظة |
|---|---|
| `Check Target Pages` | مش محتاج كريدنشيال — بيطلب صفحات الموقع بس |
| `Send via Gmail API` | مقفول افتراضيًا. شغّله من `MAIL_GMAIL_FALLBACK` في `Config` **بعد** ما تضيف صلاحية `gmail.send` على كريدنشيال جوجل |

## البنية

<div dir="ltr">

```
base/                 الملفات الأصلية كما وصلت — مرجع البنية، ما تتعدلش
src/lib/gsc.js        حساب المواضع والظهور — نسخة واحدة للتقريرين
src/nodes/shared/     ١٦ نود بنفس الكود بالحرف في الملفين
src/nodes/monthly/    الفروق الحقيقية بس (Config + شكل السلايد)
src/nodes/weekly/
src/patch.mjs         النودات الجديدة والوصلات
keywords/alojan.json  قائمة الكلمات المعتمدة + المستبعدة
tools/                البناء والفحص والمحاكاة
dist/                 الملفات الجاهزة للاستيراد
```

</div>

البناء بيرفض يكمّل لو نود موجود في `shared/` و`monthly/` مع بعض، أو لو فيه ملف
كود مالوش نود مقابل — عشان التقريرين ما يفترقوش تاني من غير ما حد ياخد باله.
