# تقارير SEO — رابح

ست تقارير (**العوجان** و**الروضة** و**شوق** × **شهري** و**أسبوعي**) بيسحبوا مواضع
الكلمات من Google Search Console، بيكتبوا في شيت، بيبنوا عرض تقديمي، وبيبعتوا
إيميل — **على كود واحد**.

## اللي اتغيّر في v4

| المشكلة | كانت فين | الحل |
|---|---|---|
| بياخد رقم أعلى صفحة ترتيبًا بدل الصفحة المستهدفة | العوجان الشهري + شوق الاتنين | كل كلمة ليها رابط، والرقم = الصفحة نفسها (`strict`) |
| `aggregationType: byPage` ناقص | العوجان الشهري + شوق الاتنين | اتضاف للأربعة |
| حارس اتقصاص رد جوجل عمره ما اشتغل (`900` مقابل `500`) | العوجان الشهري + شوق الاتنين | بيتقارن بالحد المطلوب فعلًا |
| فشل السحب بيتقال للعميل «✕ اختفت» | الأربعة | تلات حالات منفصلة: فشل · مفيش ظهور · من الأرشيف |
| `Create Slides` عليه retry وهو مش idempotent | ٣ من ٤ | اتقفل + حارس في البناء |
| رابط غلط بيطلّع «مفيش ظهور» لصفحة شغالة | الأربعة | فحص كانوني لكل رابط + شهادة من جوجل نفسه |
| التنبيهات التقنية بتروح لدومين رابح بس | الأربعة | الفلتر اتشال — التنبيه لكل المستلمين |
| إعادة الإرسال على سيرفر رافض | الأربعة | تشخيص السبب + مسار Gmail API بديل |
| ربط رد جوجل بالطلب بالترتيب مش بـ `pairedItem` | الروضة | أرقام كلمة ممكن تتلزق لكلمة تانية — اتصلّح |
| مفيش بوابة جودة أصلًا: بيكتب على الشيت مهما كانت البيانات ناقصة | الروضة | البوابة الكاملة + تنبيه بدل الكتابة |
| تعليق نموذج لغوي بيقدر يخترع رقم في فقرة رأي | الروضة | كل رقم في التعليق بيتفحص، ولو مالوش أصل التعليق كله يتشال |
| التقارير بتنحرف عن بعض | — | ٢٠ نود بنفس الكود بالحرف في الستة + اختبار بيمنع الانحراف |

الأرقام والتفاصيل: **[`docs/VERIFICATION.md`](docs/VERIFICATION.md)**

## الكلمات

| العميل | المصدر | معتمدة | مستبعدة |
|---|---|---|---|
| العوجان | إكسل · ورقة العوجان | **٢٧** من ٣٥ | ٨ (مقالات لسه ما اتنشرتش) |
| شوق | إكسل · ورقة شوق | **٢٥** من ٢٥ | ٠ |
| الروضة | نود Keywords في الأوتوميشن | **١٨** من ١٨ | ٠ |

**أي كلمة من غير رابط صفحة تُستبعد** — عشان كل رقم يبقى قابل للمراجعة في
واجهة Search Console بفلتر Query + Page.

## التشغيل

<div dir="ltr">

```bash
npm run build                     # يبني الأربعة في dist/
npm test                          # ٢٠١ تأكيد — بلا شبكة وبلا إيميلات
npm run sim -- --client=alrawda --cadence=monthly --scenario=aiInventsNumber

# تحديث قائمة كلمات
node tools/extract-keywords.mjs --xlsx=<ملف> --client=shoug
node tools/verify-pages.mjs --client=shoug      # من شبكة مفتوحة
node build.mjs
```

</div>

## الاستيراد في n8n

<div dir="ltr">

```
dist/ALOJAN-Monthly-v4.json    dist/ALRAWDA-Monthly-v4.json    dist/SHOUG-Monthly-v4.json
dist/ALOJAN-Weekly-v4.json     dist/ALRAWDA-Weekly-v4.json     dist/SHOUG-Weekly-v4.json
```

</div>

الكريدنشيال بتتحقن من ملف كل عميل: العوجان وشوق على `rabeh.seven.b`،
والروضة على `Google - rabeh.six.b`، والبريد `Rabeh SMTP` للتلاتة.
والبناء **بيرفض** يطلّع ملف نوده عليها كريدنشيال غير بتاع العميل.

| النود الجديد | ملاحظة |
|---|---|
| `Check Target Pages` | مش محتاج كريدنشيال — بيطلب صفحات الموقع بس |
| `Send via Gmail API` | مقفول افتراضيًا. شغّله من `MAIL_GMAIL_FALLBACK` **بعد** ما تضيف صلاحية `gmail.send` على كريدنشيال جوجل |
| `AI Comment API` | الروضة بس (`aiComment: true`). العميلين التانيين بيعدّوا من غير نداء ولا تكلفة |

## البنية

<div dir="ltr">

```
clients/<العميل>.json      الموقع · الشركة · الدولة · الشيت · العرض · المستلمين
keywords/<العميل>.json     الكلمات المعتمدة + المستبعدة بأسبابها
base/<العميل>/*.json       الملفات الأصلية — مرجع البنية، ما تتعدلش
src/lib/gsc.js             حساب المواضع والظهور — نسخة واحدة للأربعة
src/nodes/shared/          ٢٠ نود، ١٨ منهم بنفس الكود بالحرف في الستة
src/patch.mjs              النودات الجديدة والوصلات وتعديلات البنية
tools/                     البناء والفحص والمحاكاة
dist/                      الأربعة جاهزين للاستيراد
```

</div>

**لإضافة عميل جديد:** ضيف `clients/<id>.json` و`keywords/<id>.json`، وانسخ
`base/alojan/` كقالب بنية، وشغّل `npm run build`. مفيش كود بيتنسخ — الروضة
اتبنت كده بالظبط رغم إن ملفها الأصلي كان جيل أقدم بـ٢١ نود.

</div>
